# Food Converter

## Descrizione
Food Converter è un progetto che consente di convertire unità di misura alimentari (es. grammi, litri, tazze) in modo semplice e veloce. È progettato per aiutare cuochi, appassionati di cucina e chiunque abbia bisogno di effettuare conversioni precise durante la preparazione di ricette.

## Funzionalità
- Conversione tra diverse unità di misura alimentari.
- Supporto per unità di peso, volume e quantità.
- Interfaccia semplice e intuitiva.
- Estendibile per aggiungere nuove unità o personalizzazioni.

## Requisiti
- Node.js (versione 14 o superiore)
- npm (versione 6 o superiore)

## Installazione
1. Clona il repository:
   ```bash
   git clone https://github.com/tuo-utente/food_converter.git
   cd food_converter
   ```

2. Installa le dipendenze:
   ```bash
   npm install
   ```

## Utilizzo
Esegui il progetto direttamente dalla Shell con il comando:
```bash
npm start
```

Segui le istruzioni visualizzate nella Shell per effettuare le conversioni.
